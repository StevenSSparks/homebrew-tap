# stevenssparks/tap

Homebrew tap for [Steve Sparks](https://github.com/StevenSSparks)' open-source
utilities.

```bash
brew install stevenssparks/tap/roost
```

## Formulae

| Formula | What it is |
|---|---|
| **roost** | A captive-portal appliance emulator in a box — DNS funnel, HTTPS, live console, and a real SSH mini-shell. Test a portal OS on your laptop, then build & flash it to an ESP32. ([repo](https://github.com/StevenSSparks/roost)) |

## Usage

```bash
brew tap stevenssparks/tap
brew install roost
# or in one line:
brew install stevenssparks/tap/roost

# latest main instead of the last release:
brew install --HEAD stevenssparks/tap/roost
```
