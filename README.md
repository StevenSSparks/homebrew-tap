# stevenssparks/tap

Homebrew tap for [Steve Sparks](https://github.com/StevenSSparks)' open-source
utilities.

```bash
brew install stevenssparks/tap/webhead
```

## Formulae

| Formula | What it is |
|---|---|
| **webhead** | A captive-portal appliance emulator in a box — DNS funnel, HTTPS, live console, and a real SSH mini-shell. Test a portal OS on your laptop, then build & flash it to an ESP32. ([repo](https://github.com/StevenSSparks/webhead)) |

## Usage

```bash
brew tap stevenssparks/tap
brew install webhead
# or in one line:
brew install stevenssparks/tap/webhead

# latest main instead of the last release:
brew install --HEAD stevenssparks/tap/webhead
```
